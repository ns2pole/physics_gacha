プライバシーポリシー — 物理ガチャ

制定日: 2026年10月19日

物理ガチャ（以下「当アプリ」）は、高校物理の小問を一問ずつ解くためのアプリです。当アプリは、提供に必要なデータを端末内に保存します。オンライン保存を有効にした場合は、アカウントでログインし、同じデータを Firebase にも保存します。本ポリシーでは、収集・利用される情報、保存先、第三者提供、ユーザーの権利について説明します。

1. 収集する情報

位置情報、連絡先、写真、広告用の識別子は取得しません。解答として入力した数や式は保存しません。

オンライン保存を使うときは、次のいずれかでログインします。

  • メールアドレスとパスワード
  • 電話番号
  • Google アカウント
  • Apple アカウント

パスワードが正しいかの確認、SMS の送信、Google と Apple のログイン処理は、当アプリでは行いません。Firebase Authentication（Google LLC）と、選んだログイン先が行います。当アプリはパスワードを保存しません。

端末内に保存されるデータ

  • ガチャ設定（出題する分野、正解が続いた問題を出題から外す条件、正誤を履歴へ自動で書くかどうか）
  • 学習記録（各問題について、直近3回までの状態。未記録、正解、理解済み、不正解）

オンライン保存を有効にした場合（Cloud Firestore）

オンライン保存をオンにしたとき、当アプリは上と同じガチャ設定と学習記録を Cloud Firestore に保存します。利用者を区別するため、Firebase Authentication のユーザー識別子（UID）を一緒に保存します。ログインに使ったメールアドレス、電話番号、名前は、アカウント情報として Firebase Authentication が保持します。名前は、Google または Apple でログインしたときに、そのアカウントから渡されます。

オンライン保存をオフにしているあいだ、設定と学習記録は端末の外へ送りません。Firestore に残っているデータがある場合は、オフにしたあとも、削除するまで Firestore に残ります。

「AIに聞く」

「AIに聞く」は、当アプリにあらかじめ入っているヒントを表示する機能です。入力した解答、問題の内容、ヒントの選択は、外部のサービスへ送りません。

2. 保存先および処理者

データは次の場所に保存または処理されます。

  • 利用者の端末（アプリの保存領域）
  • オンライン保存を有効にした場合: Google Firebase（Google LLC）の Cloud Firestore と Firebase Authentication
  • Google アカウントでログインした場合: Google
  • Apple アカウントでログインした場合: Apple

端末のバックアップにアプリのデータを含める設定になっている場合、端末内の設定と学習記録がそのバックアップに入ることがあります。これは端末の機能によるもので、開発者がその内容を受け取ることはありません。

3. データの利用目的

収集した情報は、次の目的のために使います。

  • 出題条件と学習記録を、次にアプリを開いたときも残す
  • オンライン保存を有効にしたときに、設定と学習記録をクラウドに保存し、同じ利用者の端末間で揃える

広告目的のトラッキングには使用しません。

4. 第三者提供

当アプリは、収集したデータをマーケティング目的で第三者に販売したり、共有したりしません。

オンライン保存を有効にした場合、ガチャ設定、学習記録、アカウント情報を、ログインと保存のために Google LLC（Firebase）へ預けます。Google アカウントまたは Apple アカウントでログインした場合、そのログインに必要な情報は、選んだログイン先へ送られます。

5. データ保有期間

端末内の設定と学習記録は、当アプリを削除すると端末から消えます。

Cloud Firestore 上の設定と学習記録、および Firebase Authentication 上のアカウントは、オンライン保存を利用しているあいだ保持します。削除の連絡を受けたときは、合理的な期間内に消します。

6. データ削除とお問い合わせ

物理ガチャのアカウントと、クラウドに保存したデータの削除は、次のメールアドレスへ連絡してください。メールには、物理ガチャのアカウント削除であることと、ログインに使ったメールアドレスまたは電話番号を書いてください。連絡を受けたあと、合理的な期間内に、そのアカウントと、紐づくガチャ設定・学習記録を削除します。

アカウントを消さずに、クラウド上のガチャ設定と学習記録だけの削除も、同じメールアドレスで依頼できます。

端末内のデータは、アプリを削除すると消えます。

7. アプリ内解析ツールについて

  • Firebase Analytics（自動収集を含む）は使用しません。
  • 広告配信のための行動トラッキングは行いません。

8. 改定

本ポリシーを改定するときは、改定後の全文を公表し、改定日を記載します。
