# 誤植チェックリスト

表示番号はアプリ／PDF と同じ（`sampleProblems` 順）。一時除外の問も含む。

数値の綺麗さ（`answer-numbers-checklist.md`）、テーマ網羅、i18n、ラベル被り専用（`figure-label-overlap-checklist.md`）とは別目的で、解答・解説・図の正誤／誤植を見る。

## 判定基準

### 解答
- `answerValue` / `answerUnit` / `answerDisplay`（並び替えは `symbolOrder`）が、問題文・ただし書きの定数で検算どおりか
- 誤植・単位ずれ・採点値と表示の不一致は ×

### 解説
- `explanation`（必要なら `approach` / `firstStep`）の最終値が解答と一致するか
- 立式・代入の誤植・抜けは ×
- 知識・並び替えは内容の正しさで判定

### 図
- `figure` がある問: 図の数値・記号が文と一致するか＋ラベル被り／読めなさ
- 図なしは `-`
- ヒント専用図（`hintReveal`）も該当すれば見る
- ラベル被りは `figure-label-overlap-checklist.md` も参考にする

### 記号
- 未確認: 空欄
- 問題なし: ○
- 要修正: ×
- 修正済: ×→○
- 該当なし: `-`
