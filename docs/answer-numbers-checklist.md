## 判定基準

### 固定する定数
- `g = 9.8`、`π = 3.14`、`√3 = 1.73`、`ln 2 = 0.693`
- 音速 `340`、`ε₀ = 8.85×10⁻¹²`、`e = 1.6×10⁻¹⁹`、`N_A = 6.02×10²³`、`G = 6.67×10⁻¹¹`

### 揃える定数
- `R = 8.31`、`0℃ = 273 K`、空気モル質量 `29 g/mol`、地球半径 `6.4×10⁶ m`、`μ₀ = 4π×10⁻⁷`

### 答えが綺麗か
- ○: `0.98` / `1.96` / `4.9` / `29.4`、気圧の `1006.5` / `1062`、仮数 `6.2×10^6`
- できれば避ける（無理なら可）: `4.91`、仮数 `6.21×10^6`
- ×: `0.982` / `29.44`、仮数 `6.212×10^6`、および「上Nけた」前提の丸め
- 並び替え問題の「答えが綺麗か」は `-`
