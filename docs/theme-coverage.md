# 下敷きの網羅

参照は `docs/beginner_sale.pdf`。
問題の `theme` が項目名と一致したときだけチェックする。1項目につき1問が目標。
右ねじ、フレミングの左手、位相反転のような向きの注記は、項目にしない。

下敷きの項目は 210。チェック済みは 54。

仕事とエネルギーは、すべり、空気抵抗、台上の物体の3問が同じテーマになっている。理想気体の状態方程式は、ペットボトルの空気と、空気を抜いたあとの秤の2問が同じテーマになっている。
